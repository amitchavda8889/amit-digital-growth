# Amit Digital Growth — Static Professional Website

This version uses only:
- HTML
- CSS
- JavaScript

No Node.js, Next.js, PHP, Python, database or backend is required.

## Run
You can simply double-click `index.html` to preview it.

For a better local preview in VS Code, install the "Live Server" extension and choose:
Right click `index.html` → Open with Live Server.
